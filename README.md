# STRATIFY — Vanilla Offline Competition Build

This version is intentionally **offline and judge-ready**.

## Open it

Double-click `START_STRATIFY.bat`, or simply double-click `index.html`.

It opens **straight to the Home dashboard**. There is no login, account creation, server, database, API key, or internet requirement.

## Tech stack

- HTML
- CSS
- Plain JavaScript
- Browser `localStorage` for Planner/Focus/Progress persistence
- Browser Web Audio for offline ambient focus sounds

No React, Vue, Angular, Vite, Node server, database, or cloud API is required to run the competition build.

## Competition flow

Home → Planner → Strati → Focus → Progress → Social → Showcase Mode

Strati in this version is an **offline competition assistant/demo**, not a cloud generative-AI service. It can demonstrate commands such as:

- `Add Biology revision at 7 PM`
- `I finished Chemistry`
- `Start 25 minute Physics focus`
- `What's left today?`

## Reset before judging

Double-click `RESET_AND_OPEN_STRATIFY.bat` to restore the default demo Planner/Progress data.
